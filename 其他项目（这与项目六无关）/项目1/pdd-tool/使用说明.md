# 拼多多 / 1688 规格表格生成器

输入拼多多商品链接 → 自动抓取颜色 → 一键导出**拼多多**或 **1688** 可导入的 xlsx。

## 一、准备（选一种）

### 方式 A：免安装便携版（推荐，最简单）

1. 把 `pdd-portable.zip` 解压到任意文件夹（如 `D:\pdd-tool`）
2. 双击里面的 `start.bat`
3. 会自动启动并打开浏览器页面，直接用

> 不需要装任何东西。但要求电脑上有 **Chrome 或 Edge 浏览器**（一般都有）。

### 方式 B：装 Node.js 版

1. 电脑安装 **Node.js 18 或更高版本**：https://nodejs.org （下载 LTS 版，一路下一步即可）
2. 确认电脑上有 **Chrome 或 Edge** 浏览器
3. 进入 `pdd-tool` 文件夹，双击 `启动.bat`

首次启动会自动安装依赖（约 1 分钟，需联网）。

## 二、启动

看到下面这行就成功了，浏览器会自动打开：

```
请在浏览器打开：http://localhost:8787
```

如果没自动打开，手动在浏览器输入 **http://localhost:8787**。

> 窗口不要关（关了就停止服务）。用完按 `Ctrl+C` 或直接关窗口。

## 三、登录（只需一次，长期有效）

1. 点右上角「未登录」按钮
2. **会自动弹出一个浏览器窗口**，在里面正常登录拼多多即可：
   - 可以用手机拼多多 App **扫码**，也可以**手机号 + 短信验证码**
   - 这个窗口和你平时的浏览器一样，能正常显示页面；有滑块/验证也能自己完成
3. 登录成功后，网页那边会自动变成「已登录」

> 首次打开窗口要加载拼多多页面（需下载几百 KB 的网页资源），**可能要等十几秒到几十秒**，页面出来前窗口是白的，属正常。
> 加载过一次后，缓存会留在 `.browser-cache` 文件夹里，之后启动就快了。

登录态保存在本机 `auth.json`，之后打开直接用。想换账号：点「已登录」→ 退出。

## 四、使用

1. 先在「导出格式」里选要哪种表（可选「设为默认」，下次打开就是它）：
   - **拼多多**（可直接导入拼多多）
   - **1688 商品表**（16 列，每个 SKU 一行）
   - **1688 SKU表**（4 列：属性名/值）
2. 复制拼多多商品链接（App 里「分享 → 复制链接」），粘到「商品」框
3. 点「抓取」——自动识别商品编号、颜色；1688 格式下还会自动填商品标题、拼单价、SKU 图
4. 需要的话填「拼单价」，然后点「+ 加入清单」（可连续录多个商品）
5. 点右上角「导出」

- 拼多多格式：单个商品直接下 xlsx，多个商品打包成 zip
- 1688 格式：导出单个 `商品批量导入.xlsx` 或 `SKU规格导入.xlsx`
- 快捷键 <kbd>Ctrl</kbd>+<kbd>Enter</kbd> 导出

### 1688 格式字段对照

| 来源 | → 1688 字段 |
|---|---|
| 颜色分类（抓取/手输） | SKU属性1值（属性名默认「颜色」，可改） |
| 参考分类尺码 | SKU属性2值，写成 `80cm`、`90cm`…（不含「正码正拍」） |
| 拼单价 | SKU价格（所有尺码统一，不做减 2 元规则） |
| 库存 | SKU库存 |
| 商品标题 | 商品标题列（抓取或手输，超 128 字自动截断） |
| 商品编号 | 货号/型号（写成 `584#`） |
| — | 各图片列**留空**，需你手工补图 |

多商品时序号自动递增（1、2、3…）且同一商品的各行序号一致。
若每个商品标题不同，可在清单里写 `<code>编号|颜色|价格|标题</code>（第4字段可选）。

## 五、规则说明

**拼多多格式**
- 颜色分类：抓取或手输，多个用 `/` 分隔
- 参考分类（尺码）：填起始/结束/间隔，自动补齐并追加「正码正拍」
- 价格：单买价 = 拼单价 + x（x 默认 2）；**最小尺码**和**正码正拍**两行，拼单价/单买价均少 2 元
- 规格编码：`商品编号#颜色分类-参考分类`
- 导出文件完全套用拼多多官方模板（提示行、Sheet0、样式一致），可直接导入

**1688 格式**
- 套用 1688 官方模板（表头、样式、合并单元格保留），只填数据区
- 行 = 颜色 × 尺码；序号按商品分组递增
- 图片列留空（1688 要求图片必填，需手工补）

## 六、出问题了怎么办（看日志）

点页面右上角「**日志**」，会弹出完整运行日志，可以：

- **刷新**：重新读取最新日志
- **下载**：存成一个 txt 文件
- **清空**：清掉旧日志

日志文件在程序目录下的 `logs/app.log`。**二维码没出来时**，程序会额外把当时的页面截图存到 `logs/login-fail.png`。
把 `logs` 文件夹（或下载的 txt）发给我，就能定位问题。

## 七、常见问题

**点登录后二维码出不来**
正常做法是**弹出一个浏览器窗口，你自己在里面登录**（不是二维码）。
若窗口没弹出：看下任务栏，可能被其他窗口挡住；或点右上角「日志」把日志发我。

**抓取失败，提示登录态过期**
重新点右上角登录按钮扫码即可。

**提示「没抓到颜色规格」**
该商品规格可能只在 App 内展示，或商品已下架。可手动填颜色。

**启动时报错「'node' 不是内部或外部命令」**
电脑没装 Node.js。改用 `pdd-portable.zip`（免安装版），或去 nodejs.org 装 LTS 版。

**启动脚本乱码 / 报奇怪的命令错误**
已修复（脚本改为纯英文）。请用最新版。

**端口被占用（EADDRINUSE）**
换个端口启动：`PORT=8888 node server.mjs`（Windows：`set PORT=8888 && node server.mjs`）

**找不到浏览器**
设环境变量 `CHROME_PATH` 指向 Chrome 可执行文件。
